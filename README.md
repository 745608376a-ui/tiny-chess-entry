A chess engine in at most 4,096 bytes of Python: negamax alpha-beta search (PVS) with quiescence, a transposition table, killer/history ordering and null-move pruning, an incremental tapered piece-square evaluation, and a fixed node budget so every move is deterministic.

## Run it

```sh
MAKEFUN_ENV_URL=http://localhost:8080 python3 main.py
```
